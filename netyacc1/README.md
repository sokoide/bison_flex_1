# netyacc1

## About

* .NET (C#) port of [goyacc1](../goyacc1): a tiny arithmetic expression
  evaluator driven by a YaccLexTools-generated parser and scanner.
* It mirrors `goyacc1/hoge.go.y`: `%left '+' '-'` / `%left '*' '/'` precedence,
  `NUMBER` token, `( expr )`, and a `program : expr` rule that prints the result.
* Unlike the other examples this is a REPL: it reads one expression per line.

## Files

* `Calc/Calc.Language.grammar.y` ... grammar (input to YaccLexTools)
* `Calc/Calc.Language.analyzer.lex` ... lexer specification
* `Calc/Calc.Parser.Generated.cs` / `Calc/Calc.Scanner.Generated.cs`
  ... generated by YaccLexTools during build (checked in)
* `Calc/Calc.Parser.cs` / `Calc/Calc.Scanner.cs` ... hand-written partial classes
* `Program.cs` ... REPL entry point

## Prereqs

* .NET SDK
* <https://github.com/ernstc/YaccLexTools>
  * `dotnet tool install dotnet-ylt --global`
  * only needed to regenerate the parser/scanner from the `.y` / `.lex` files
    (the generated `.cs` files are committed, so a plain build does not need it)

## How to run

```sh
cd netyacc1
dotnet run
```

Enter one expression per line (`Ctrl+D` or an empty line to exit):

```text
> 1+2*3
7

> (4+1)*4/2
10
```

## Notes

* The project targets **.NET 7**. If your machine has only a newer runtime
  installed, run with `DOTNET_ROLL_FORWARD=Major dotnet run`.
* There is no unit test project here; use `goyacc1` for the tested Go version.
